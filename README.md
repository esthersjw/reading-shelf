# 心理学书库知识网络数据 - data-psychology.json

## 文件说明

本文件为8本心理学书籍的**章节级别核心观点提取**，以结构化JSON格式保存。

## 提取标准

✅ **提取的是具体的、有判断力的观点**，而非抽象概念
- 不是"课题分离"（概念），而是"一切烦恼的根源是你干涉了别人的课题"（观点）
- 不是"依恋理论"（理论），而是"依恋类型决定了你在关系中的表现模式"（洞见）

✅ **每个观点都包含**：
- `point`: 核心观点（一句话，犀利、有态度）
- `explanation`: 2-3句展开解释（帮助理解为什么这很重要）
- `example`: 具体的生活场景（有画面感、容易代入）
- `bookId`: 来源书籍ID（便于追溯和知识关联）

## 使用场景

### 1. 构建知识图谱
这些观点ID和bookId可用于构建心理学知识的关联网络：
- 观点间的冲突与补充
- 不同书籍对同一主题的不同角度
- 观点的应用场景和生活关联

### 2. 快速查阅
需要某个具体观点时，可通过观点ID快速定位
- 例如：搜索"courier-unhappiness-is-chosen"找到《被讨厌的勇气》中关于不幸源头的洞见

### 3. 读书笔记关联
与其他知识库的连接：
- 关联到具体场景、案例分析
- 与实践工具、建议相关联
- 与其他心理学流派的比较

### 4. 内容创作
用于生成：
- 书评、解读文章
- 播客或视频脚本
- 工作坊或分享会的素材

## 关键设计决策

### 为什么选这些观点？
- **每本书5-7个观点**：精选最犀利、最改变思维的洞见，避免冗余
- **跨越整本书**：不是按章节线性提取，而是选择最有冲击力的核心观点
- **实用导向**：优先选择能立即改变人们思考和行动方式的观点

### 为什么要求"有判断力"？
- 对比"系统1和系统2存在"（事实陈述） vs "人太懒，常用系统1导致错误决策"（有判断）
- 后者让读者产生"哦原来是这样"的顿悟感，而前者只是信息堆砌
- 这种观点更容易被记住、应用、传播

### 为什么每个例子都很具体？
- "比如在工作中……" ❌ 太模糊
- "一个销售每天打电话但看不到成果，而程序员每保存代码都能看到反应" ✅ 有画面感

## 下一步可能的扩展

1. **edges.json**：观点间的关联关系
   - 冲突关系：哪些观点相互矛盾或补充
   - 应用关系：这个观点如何应用到其他学科
   - 层次关系：基础观点 → 进阶观点

2. **scenarios.json**：具体生活场景与观点的映射
   - "我在关系中总被伤害" → 推荐的观点和书籍
   - "我觉得生活没意义" → 推荐的观点和书籍

3. **applications.json**：观点如何应用在实践中
   - 冥想、习惯改变、沟通练习等具体行动

4. **comparisons.json**：不同书籍对同一主题的观点比较
   - 例如，所有书都讨论改变，但角度不同
