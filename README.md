# 📚 不二的书架 — 知识网络可视化

把读过的书拆解为核心观点，用「书架浏览 + 观点网络」两种视角呈现书与书之间的隐藏连接。

**在线体验** → [esthersjw.github.io/reading-shelf](https://esthersjw.github.io/reading-shelf)

---

## ✨ 功能

- **书架视图** — 按 6 大分类浏览 55 本书，每本展示一句判定、核心金句、章节级洞见
- **观点网络** — D3.js 力导向图，295 个观点节点，可视化跨书关联，拖拽 + hover 高亮连接路径
- **书籍详情** — 点开每本书查看完整章节拆解，每个观点有论断 + 解释 + 生活场景
- **AI 添加新书** — 输入书名，AI 自动拆解为结构化观点并加入书架
- **移动端适配** — 响应式设计，手机端可流畅浏览

## 🚀 使用

纯前端项目，无需安装依赖：

```bash
git clone https://github.com/esthersjw/reading-shelf.git
cd reading-shelf
open index.html
```

## 📁 项目结构

```
reading-shelf/
├── index.html       # 主页面（结构 + 样式）
├── app.js           # 应用逻辑（书架渲染 + 网络图 + AI添书）
├── d3.v7.min.js     # D3.js（本地化，离线可用）
├── data.json        # 55本书的结构化数据
├── fonts/           # 字体文件（本地化，无外部依赖）
├── avatar.png       # 头像
└── README.md
```

## 🧠 数据结构

每本书被拆解为章节级核心观点：

```json
{
  "bookId": "courage-to-be-disliked",
  "title": "《被讨厌的勇气》",
  "author": "岸见一郎、古贺史健",
  "category": "psychology",
  "verdict": "一句话判定",
  "highlights": "全书最精彩的3个洞见",
  "chapters": [
    {
      "chapterName": "章节名称",
      "insights": [
        {
          "id": "唯一观点ID",
          "point": "核心观点（一句犀利判断）",
          "explanation": "2-3句展开",
          "example": "具体生活场景",
          "keywords": ["关键词"]
        }
      ]
    }
  ]
}
```

### 观点提取标准

- ✅ 有判断力的观点，不是抽象概念
- ✅ 每个例子具体到有画面感
- ✅ 跨越全书精选最有冲击力的洞见

## 🎨 设计

- **配色**：米白底 `#fefcf6` + 蓝色主调 `#2B7FD8` + 金黄点缀 `#F4D758`
- **字体**：Playfair Display（标题）+ DM Sans（正文英文）+ 系统中文字体
- **网络图**：D3.js v7 力导向布局，节点按书着色，hover 高亮关联路径
- **离线友好**：字体和 D3.js 均本地化，无外部 CDN 依赖
